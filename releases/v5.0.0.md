# Pokémon FireRed Multiplayer v5.0.0

Versão histórica do projeto com exploração local, duelos e batalhas cooperativas, além da escolha de iniciais aleatórios.

**Limitação conhecida:** a seleção aleatória pode mostrar a mesma espécie em mais de uma Pokébola. Para uma nova campanha, use a v6.0.0.

## Download e compilação

Baixe o arquivo `pokemon-fire-red-multiplayer-v5.0.0.patch` nos assets desta release ou o código-fonte no fim da página. O patch precisa da revisão de `pret/pokefirered` e de uma ROM base legal de Pokémon FireRed (EUA, revisão 1.0), fornecida pelo próprio usuário. Siga o README do repositório para aplicar o patch e compilar.

Esta release não contém ROM, BIOS, saves ou save states.
