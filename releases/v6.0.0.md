# Pokémon FireRed Multiplayer v6.0.0

Versão recomendada. Corrige a consulta do índice de cada Pokébola: ao ativar os iniciais aleatórios, as três opções mostram espécies diferentes.

## Download e compilação

Baixe o arquivo `pokemon-fire-red-multiplayer-v6.0.0.patch` nos assets desta release ou o código-fonte no fim da página. O patch precisa da revisão de `pret/pokefirered` e de uma ROM base legal de Pokémon FireRed (EUA, revisão 1.0), fornecida pelo próprio usuário. Siga o README do repositório para aplicar o patch e compilar.

Esta release não contém ROM, BIOS, saves ou save states.
